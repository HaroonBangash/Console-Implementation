# SkillForge UI

A minimal, accessible Next.js prototype showcasing the SkillForge learning experience.

## Getting started

```bash
pnpm install
pnpm dev
```

The development server runs on [http://localhost:3000](http://localhost:3000). No backend services are required.

## Tech stack

- Next.js (App Router) + TypeScript
- Tailwind CSS with shadcn/ui-inspired components
- Recharts for lightweight analytics visuals

## Key flows

1. Login with MFA challenge
2. Student dashboard with learning, labs, assessments, credentials, and jobs
3. Programme catalogue and detail pages with enrol state
4. Virtual lab workspace and assessment submission journeys
5. Credential wallet, verification, and employer jobs view
6. Trainer, admin, and analytics dashboards

All data is sourced from `/mock-api` TypeScript files.
